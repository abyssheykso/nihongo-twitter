AI API 設定

ツイートを添削するAIのAPIを設定します。設定はこのブラウザ（localStorage）に保存されます。 OpenAI 互換のエンドポイントに対応しています。

注意事項

ブラウザから直接APIを呼ぶため、CORS に対応したプロバイダーが必要です。 OpenRouter や SiliconFlow はブラウザから利用しやすいです。接続できない場合は、 別のプロバイダーか自前のプロキシをお試しください。 APIキーはこの端末のブラウザにのみ保存され、外部には送信されません。
